# Welcome to Lythic

Lythic is an AI-augmented Obsidian note-taking system.

## Features (roadmap)

- Vault intelligence — embeddings & semantic search locally via vault index
- Graph enhancements — inferred links, clusters, and temporal views
- Multi-agent workflows — OpenCode pipeline (@architect → @test-engineer → @implementer)

## Quick Start

```bash
opencode
/context-prime
@architect "Design vault intelligence pipeline for Obsidian"
```

## Vault Structure

- `vault/` — your markdown notes (this file is the entry point)
- `src/` — Obsidian plugin source (`src/main.ts`)
- `.opencode/` — 7 agents, 8 commands, 5 skills, compaction plugin

> Built from Tools_AI-MCP starter-pack, upstream is Lythic (Lithic_note-taking-system).
