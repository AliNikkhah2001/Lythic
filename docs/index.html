01 / Decision

Start from Atomic.
Design the vault layer first.

Recommended path

Fork the architecture, not every assumption.

Atomic is the closest MIT-licensed match: Rust, Tauri, CodeMirror, SQLite, vector search, graph rendering, server clients and MCP. Make Markdown files canonical and every index rebuildable.

Atomic on GitHub →
Borrow

SilverBullet’s programmability

Queries, commands, templates and sandboxed extensions.

Preserve

Obsidian-style file ownership

Markdown and attachments remain useful without the app.

License boundary

Study AGPL projects carefully

Logseq and TriliumNext are references unless the project deliberately chooses AGPL.

04 / Added functionality

Make the graph useful.

01

Graph lenses

Combine explicit, semantic, temporal, source, task and property edges.

02

Temporal graph

Replay how the vault evolved and compare meaningful dates.

03

Atomicity coach

Review suggested splits, merges, links and bridge notes as diffs.

04

Provenance-first AI

Cite exact notes, blocks, sources, retrieval details and model versions.

05

Saved graph views

Store query, filters, layout and annotations as portable files.

06

Knowledge health

Find orphans, stale hubs, broken links, duplicates and bridge notes.

05 / Roadmap

    Graph engine

    4–6 weeks · typed edges, lenses, health and saved views

    Intelligence
